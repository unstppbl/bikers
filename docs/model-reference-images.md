# Model reference images

The catalogue contains **22 canonical models** and **25 verified exact-year reference images**. Images are public catalogue assets, independent of rider accounts and private garages. Each entry matches only its documented model year; no broader generation range is inferred. Unsupported years have no image.

Images are copied unchanged from Wikimedia Commons originals or published resolution variants, including the KTM Adventure PNG’s original transparency. The manifest records source evidence, download URL, dimensions, SHA-256, credit, and license. No visual edits or AI generation were used.

## Adding coverage

Verify the exact model, trim, and model year from the source description or stronger manufacturer evidence. Keep capture year, build year, and model year distinct. Retain the source evidence, author, and license; add the unchanged local asset, manifest entry, and models catalogue entry. Never infer a generation range from visual resemblance or use a nearby year as fallback.

The public Wikimedia API can supply file metadata and published resolutions during this offline curation process. It does not certify motorcycle identity or model year. API options and generated-image tradeoffs are compared in [Motorcycle photo API research](motorcycle-photo-api-research.md). Paid-provider integration and generated artwork remain proposals; neither has been added to the verified catalogue.
