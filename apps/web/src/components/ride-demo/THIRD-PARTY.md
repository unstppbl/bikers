# Ride demo source and licenses

The `kit/` directory contains the minimum dependency closure used from Stageshow,
Copyright (c) 2026 Benji Taylor, under the MIT license in `LICENSE-STAGESHOW.txt`.
The component began from the skill's `examples/dark-hero` compact composition,
with the measured cursor choreography of `examples/share`. BIKERS.KZ adapts the
composition, content, timing, tokens, and localized story; it does not include
other products' artwork or the skill's example/teaching libraries.

Icons use the application's `@phosphor-icons/react` dependency under its MIT license.
Fira Sans and Fira Sans Extra Condensed, with their OFL notice, come from the host application's self-hosted fonts. The demo fetches no fonts, images, or API data.
